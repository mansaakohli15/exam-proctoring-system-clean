# 🎯 Exam Proctoring System

An AI-based exam proctoring system that monitors students during online exams using computer vision techniques.

---

## 🚀 Features

- 🎥 Real-time webcam monitoring  
- 👀 Face detection  
- ⚠️ Suspicious activity detection  
- 🧠 AI-based behavior analysis  
- 📊 Simple and clean interface  

---

## 🛠️ Technologies Used

- Python  
- OpenCV  
- NumPy  
- Machine Learning (Detection Logic)  

---

exam-proctoring-system-clean/
│── main.py

## ⚙️ Installation

1. Clone the repository:
git clone https://github.com/mansaakohli15/exam-proctoring-system-clean.git

2. Navigate into the folder:

cd exam-proctoring-system-clean


3. Create virtual environment:

python -m venv venv
venv\Scripts\activate


4. Install dependencies:

pip install -r requirements.txt
